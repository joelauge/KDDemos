# Files and limits

## File types KnowBot reads

Source: /studio/

KnowBot Studio accepts PDF (.pdf), Word (.docx), PowerPoint (.pptx), Excel (.xlsx), web pages (.html, .htm), Markdown (.md, .markdown), text (.txt, .csv), images (.png, .jpg, .jpeg, .webp, .gif) and audio (.mp3, .wav, .m4a, .ogg). A file's contents must match its extension; a file that does not is refused.

## Size limits

Source: /studio/

In KnowBot Studio a single file can be up to 95 MB, and one trial bot can hold up to 100 MB of files in total. The capacity bar shows how much room is left, for example "96.1 MB left". Sample files count toward the 100 MB.

## What happens to a file after upload

Source: /studio/

Each file goes through real processing stages, shown live in Studio: uploaded, extracted, chunked, atomized, encoding your knowledge and ready. Atoms are the small passages KnowBot searches and quotes. You can ask your bot questions as soon as the first file is ready; answers then come from the files that are ready so far.

## When a file fails

Source: /studio/

If a file cannot be read, Studio says why. "No readable text found. It looks like a scanned image." means the file has no text layer. Other messages cover unsupported formats, files too large to process, and timeouts. You can remove a failed file and try another.

## The Knowledge Map

Source: /studio/

The Knowledge Map in KnowBot Studio shows your files as dots: each dot is one atom, grouped by file. The positions show which file an atom came from; they do not show meaning.

## Seven-day trial storage

Source: /studio/

A trial bot and its files are kept for 7 days. Studio shows "Saved for 7 days" and a countdown from day 5. After the trial expires, its files are deleted from the store. Launching the bot keeps your files.
