What “Create link” does in production

  1. Mints a read-only, store-scoped token: POST /-/apitokens/mint {aud: <store id>, sub: link:<id>, scp: "search:read", ttl}. It can never exceed the creator’s own entitlements.
  2. Saves link id → {store, tag_query, fields, limits, token} on the server. The URL holds only the opaque id, so the token never appears in a chat.
  3. Each search is proxied to GET /api/v1/vector_stores/{id}/search with the scope and field projection enforced server-side. Snippets, files and media modes are switched off unless the link grants them.
  4. Revoke calls /-/apitokens/revoke. Every copy of the link stops working, including ones forwarded to other chats.
